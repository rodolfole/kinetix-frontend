## Recommended order

1. Delete local-only `dist/` and `.astro/` (regenerated; ignored).
2. Delete `tailwind.config.mjs`, the `lucide` dependency, and the 5 empty directories.
3. Delete unused `shared/components/forms/{FormCheckbox,FormInput,FormRadio,FormSelect,YearSelect,FormLabel,FormError}.astro` and trim `forms/index.ts`.
4. Delete the duplicate `personalInfoRegistrationSchema`/`raceInfoSchema` in `lib/validation.ts`.
5. Rename `lib/mock-data.ts` to `lib/format.ts` (5 imports + test); update README/AGENTS.
6. Rename dashboard `EventCard.astro` to `OrganizerEventCard.astro`.
7. Merge the `Backend*` types into one module and the slug lookup into one helper.
8. Fix the registration flow (RED test, real endpoint) and then delete `registration.action.ts` and `pages/registration/exito.astro`.
9. Delete the unused `event.update` action (or the `/api/events/[id]` route) after confirming nothing calls it by URL.
10. Merge the two sidebars and the two layouts; merge `Layout.astro` into `MainLayout.astro`.
11. Unify `Button` on starwind; consolidate icon packages (needs visual checks).
12. Add `.gitattributes`, normalize line endings in a dedicated commit; update stale docs; move `PERFORMANCE_REPORT.md` into `docs/reports/`; split `[eventSlug].astro` (see `ISLANDS_AND_PREACT.md`).
